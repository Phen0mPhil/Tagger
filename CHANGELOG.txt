PHOTO TAGGER — VERSION CHANGELOG
================================================================================

v1.1.0 (2026-10-03)
--------------------------------------------------------------------------------
MAJOR FEATURES:
• Standalone Dual-Pane Comparison Workspace (compare.html & compare.js):
  - Air-gapped side-by-side inspection running in its own isolated browser tab.
  - Interactive breadcrumbs and clickable subfolder hops per pane via nav.js.
  - Synchronized zoom and drag-pan mirroring across both panes.
  - Instant pane flipping (Swap Sides / "S" key) preserving transform states.
  - Dedicated tagging targeting (Pane A, Pane B, or Both) with full palette modal.

• Decoupled Directory Navigation Engine (nav.js):
  - Reusable component factory (createDirectoryNavigator) handling breadcrumbs
    and subfolder navigation pills across both main and compare views.

• Persistent Multi-Folder Sequence Deck (deck.js):
  - Staging drawer decoupled from grid selection, stored persistently in localStorage.
  - Cross-directory sequencing: queue photos across separate directories and drives.
  - Permissive queuing: allows duplicate entries for custom pacing loops.
  - Deck Inspection Tray (Deck: X button) with thumbnail strips and single-click eviction.

• Advanced Slideshow Engine (viewer.js):
  - Variable speed selector directly in viewer header (1s, 3s, 5s, 15s, 30s).
  - True Fisher-Yates random shuffle toggle (🔀).
  - In-flight pruning: press Delete / Backspace or click Evict during playback to 
    drop the current photo from the Deck sequence on the fly without halting loop.
  - Full-folder traversal support in lightbox mode via arrow keys and side controls.

• Search & Filter Enhancements (grid.js):
  - Dedicated Exclude (-negative) input for instant "See All Except" filtering.
  - Recursive "Deep" scanning imports tags from nested subfolder catalog.json sidecars.
  - Persistent selection state during consecutive batch tag operations.
  - In-place DOM tag updates eliminating scroll position jumping.

ARCHITECTURAL & MEMORY OPTIMIZATIONS:
• Full Modular Decoupling:
  - Extracted monolithic scripts into discrete modules (panzoom.js, nav.js, state.js, 
    deck.js, api.js, grid.js, presets.js, viewer.js, compare.js, app.js).
• GPU & RAM Containment:
  - Layout preservation with visual occlusion (visibility: hidden) during fullscreen
    inspection to preserve scroll coordinates while freeing graphics cycles.
  - Immediate texture purging (img.src = "") on slide transition and viewer close.
  - View-frustum DOM containment (content-visibility: auto) for large catalog scrolling.
  - On-the-fly 800px thumbnail generation cached in .cache/thumbnails.

BUG FIXES & STABILITY:
• Replaced PowerShell Form picker with native Windows Shell.Application COM object to 
  guarantee folder dialogs mount directly to the foreground.
• Eliminated duplicate variable declarations across modules that prevented viewer initialization.
• Universal path canonicalization across Windows drive letters and slash formats.
• Added dedicated one-click clear button (✕) to search and exclude filter bars.
