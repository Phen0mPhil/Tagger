Photo TaggerA local, single-binary photo cataloging, inspection, and rapid-triage utility built with Go and embedded Vanilla JS / Tailwind CSS.The app runs as a lightweight local daemon, launches your browser automatically, and writes non-destructive catalog.json sidecar files directly inside the scanned photo directories.🌟 Features📁 Smart Directory & Breadcrumb NavigationNative Foreground Folder Picker: Spawns Windows directory dialogs without opening background console windows (CREATE_NO_WINDOW).Interactive Breadcrumbs: Jump directly up directory trees (D: / photos / 2026) with one click.Subfolder Quick-Hop Pills: Clickable child folder buttons to dive directly into subdirectories without reopening system pickers.Subfolder Scoping: Toggle between flat scans (current folder only) vs. deep recursive indexing.🔍 Advanced Boolean Search & FilteringConjunction (AND): Search multiple terms (beach portrait) to find photos matching all conditions.Exclusion (NOT): Prefix terms with - (bikini -sunset) to exclude unwanted tags or filenames.Untagged Quick View (★ Untagged): One-click toggle to isolate all unclassified photos for batch triage.🖥️ Fast Triage & Grid ControlsDual Interaction Modes:Inspect Mode (🔍): Click any card to open the fullscreen high-resolution viewer.Select Mode (☑): Click anywhere on a photo card to toggle selection for batch tagging.Dynamic Density: Instant layout switching (Dense (S), Standard (M), Large (L)).DOM RAM Protection (Pagination): Fast chunk rendering (30, 60, or 100 items per page) to prevent browser memory spikes on massive 4,000+ photo libraries.Pitch-Black UI (#000000): Neutral dark theme designed so photo color profiles and skin tones pop with zero ambient light bleed.🖼️ Fullscreen Viewer & Targeted SlideshowHigh-Res Lightbox: Deep inspection with file names, counter stats, and instant tag badges.Dual-Target Slideshow:If images are selected $\rightarrow$ runs slideshow only on the selected subset.If nothing is selected $\rightarrow$ plays through all images passing the active search filter.Playback Controls: Auto-advancing loop (3s interval) with play/pause toggles and arrow navigation.⚡ Palette Presets & Keyboard Speed-RunCustom Tag Palettes: Create, edit, and persist custom tag groups in localStorage.Docked Preset Pills: Fast stamp tags numbered [1] through [9].Typing Guard: Hotkeys automatically disable while typing in inputs to prevent accidental tagging.⌨️️ Hotkey Cheat SheetKeyContextAction1 – 9Global / LightboxStamp preset tag in slot 1–9 to active photo or selected batchSpaceLightboxToggle selection checkmark on currently viewed photo→ (Right Arrow)LightboxNext image← (Left Arrow)LightboxPrevious imageEscapeLightboxClose fullscreen viewerTGlobal GridToggle between Inspect Mode and Select ModeEnterSearch / InputSubmit folder scan or add custom tag🛠️ Build & DevelopmentProject Structuretagger/

Compiling to a Single Windows .exeRun this inside your WSL / Linux terminal:GOOS=windows GOARCH=amd64 go build -ldflags "-H=windowsgui" -o tagger.exe .
-ldflags "-H=windowsgui" compiles the binary as a native GUI application so no black terminal window flashes when launched.All HTML, CSS, and JS assets are compiled directly inside the .exe via embed.FS.📄 LicenseMIT License. Free for personal and commercial use.
